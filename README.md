# Обработка Excel-файлов

Программа собирает таблицы из папки `input` в один файл `result.xlsx`.
Нужен Python 3.10 или новее (при установке Windows отметьте **Add Python to PATH**).

## Первый запуск

1. Скачайте проект и распакуйте его в папку.
2. Откройте терминал в этой папке (в Windows можно ввести `cmd` в адресной строке проводника).
3. Установите зависимости:

   ```sh
   python -m pip install -r requirements.txt
   ```

4. Запустите обработку:

   ```sh
   python main.py
   ```

5. Откройте появившийся рядом файл `result.xlsx` в Excel.

В macOS/Linux вместо `python` может понадобиться `python3`.
Перед повторным запуском закройте `result.xlsx` в Excel: результат перезаписывается.
Пути считаются относительно папки скрипта, поэтому запускать его можно из любой папки.

## Свои файлы

В `input` уже лежат пять тестовых файлов. Уберите их и положите свои `.xlsx`.
На первом листе каждого файла должны быть заголовки:
`Дата`, `Клиент`, `Телефон`, `Товар`, `Цена`. Порядок колонок может быть любым.
Цена — число или текст вида `100,50`, без формул, от нуля и с точностью до копеек.
Телефоны принимаются с 8, +7 или без кода страны, с пробелами, скобками и дефисами.

Результат содержит:

- **Данные** — корректные покупки с телефонами вида `+79991234567`.
- **Ошибки** — исходные строки с причиной ошибки, именем файла и номером строки.
- **Итоги** — суммы по клиентам только из листа «Данные».

Полные дубли удаляются по всем пяти исходным полям среди всех файлов, включая
ошибочные строки. Разный формат телефона сам по себе не делает две покупки дублями.
Клиенты группируются по точному написанию имени. Пустые или неверные телефоны,
пустые или неверные цены, пустые имена клиентов попадают в ошибки.
Полностью пустые строки и временные файлы Excel `~$…xlsx` пропускаются.

## Тестовые данные и проверка

Чтобы заново создать примеры, сначала переместите существующие `example_*.xlsx`
из `input`, затем выполните `python generate_examples.py`. Генератор не перезаписывает файлы.

Для автоматической проверки выполните:

```sh
python -m unittest -v
```

В исходных примерах: 16 строк, 3 полных дубля, 8 корректных покупок и 5 ошибок.
Итоги: Анна — 600,60; Борис — 500; Вера — 75,50; Дарья — 25.
Проверки работают во временной папке и не меняют ваши Excel-файлы.
